# 共通ルール（AGENTS.md）

> このファイルは Claude Code 以外の AI ツール（Cursor / Windsurf 等）が最初に自動で読むエントリポイントです。
> ルールの本体は **`ai-guideline.md`**（プロジェクトルート）に集約されています。このツールが `@ファイル` 形式のインポートを解釈できない場合に備え、要点だけをここに直接書いています。詳細・最新版は必ず `ai-guideline.md` を参照すること。

## 最優先の方針

**シンプルかつ確実な解決を最優先する。** 複雑な解決はそれだけで失格。動くかどうか不確かな巧妙な解決より、確実に動くシンプルな解決を選ぶこと。

## 基本ルール（要約）

- 返答は日本語・簡潔に。実行前に変更内容の概要を伝えること
- 実装前に「論理的な破綻がないか」を検証すること（Simple First・Step-by-Step）
- 推測で進めず、ファイルを読んで事実を確認してから直すこと
- 抽象化・汎用化は必要になってから行う。最初から過剰設計しない
- `AI_CONTEXT.md` を作業開始時に必ず読み、重要な変更後は必ず更新すること
- 大きな変更の前には「修正予定ファイル」と「処理ステップ」を提示し合意を得ること
- コメントは日本語・簡潔に。既存のコードスタイルに合わせること
- 期待どおりに動かないときは推測で直さず、まず原因を特定すること
- 何かを変える前に必ず `git commit`。1回の会話で1つだけ変える。動いたらすぐコミット

## 詳細ルールへの案内

上記は要約です。トークン節約の指針・AI_CONTEXT.md の管理方法・バイブコーディング規律・非エンジニア向け安全規則・説明強度の使い分けなど、詳細は **`ai-guideline.md`** を参照すること。プロジェクト固有ルールも `ai-guideline.md` の末尾に追記されている。
